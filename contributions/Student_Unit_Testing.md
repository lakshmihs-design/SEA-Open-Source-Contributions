# Unit Testing

## Introduction
Unit testing is a software testing method used to test individual functions or components of software.

## Example
Consider a calculator application. We can test the addition function separately to check whether 5 + 3 gives 8.

## Advantages
- Helps identify errors early
- Makes debugging easier
- Improves software quality

## Conclusion
Unit testing verifies that individual components work correctly before they are combined into a complete system.
